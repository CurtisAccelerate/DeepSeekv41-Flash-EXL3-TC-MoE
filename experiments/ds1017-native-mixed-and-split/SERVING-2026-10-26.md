# Serving selection after the October 26 measurements

The measurements are in the 1017 report:
[2–8 user attention, October 26](https://github.com/CurtisAccelerate/DeepSeekv41-Flash-1017-EXL3-CMP170HX/blob/main/benchmarks/2026-10-26/README.md).

This bundle remains the published C1 source: native mixed experts, split
attention, and the captured K5 drafter. The 2-8 user lane is separate source,
default off, in [experiments/ds1017-r2-b2-b8](../ds1017-r2-b2-b8/README.md).
DSV41_R2 is the master flag. It does not turn that lane on by being present
in the repository.

## What the measurements say to run

- New attention for every batch size, including 7 users padded onto the 8-user graph.
- A single temperature-1 request samples the drafter.
- Batches of 2–8 leave the drafter greedy.
- A temperature-0 request stays greedy at every batch size.
- Draft length stays 5.

Draft length 7 and the Mia weights are not part of this selection.

## Image

There is still no pullable image. The October 25 note stands: this tree is
source plus integration guidance, not a server image and not an installer.

The next packaging step is one image that boots the selection above, with
admission still a separate switch. That image is not published here. Until it
exists, a server does not pick up the 2–8 user graphs, or the one-request
sampled drafter, by cloning this repository.
